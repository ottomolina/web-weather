# Web Weather

Este proyecto es una página web que muestra el clima de una lugar que previamente se ha buscado.

## Configuración

Si no ha instalado [Angular](https://angular.dev/tools/cli/setup-local), necesitas ejecutar el siguiente comando para instalarlo:

```bash
npm install -g @angular/cli
```

Si instaló [git](https://git-scm.com/downloads) puede clonar el código a su equipo.

- Ejecuta el siguiente comando de [git](https://git-scm.com/downloads) para clonar el proyecto a su equipo.

```bash
git clone https://github.com/ottomolina/web-weather.git
```

- Una vez finalizada la clonación, desplácese a la carpeta que se ha creado:
```bash
cd web-weather
```

- Ejecuta el siguiente comando de [Angular](https://angular.dev) para iniciar la aplicación en modo de desarrollo:
```bash
ng serve --open
```
Navega en un explorador de internet hacia `http://localhost:4200/`.
